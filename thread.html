螺纹参数图解

牙型、大径中径小径、螺距导程、旋向、导程角、公差标记、加工和测量……一张图一个参数，看动画就懂。

00螺纹是怎么来的

一个直角三角形卷到圆柱上，就是螺旋线
拿一张直角三角形的纸，底边等于圆柱的周长 π d，高等于导程 Ph，把它卷到圆柱上，斜边就绕成了一条螺旋线。再让一个三角形（或梯形）的牙型沿着这条螺旋线扫过去，圆柱上就长出了螺纹。
  • 在圆柱外表面上的叫外螺纹（螺栓、螺钉），在孔里的叫内螺纹（螺母、螺孔）。
  • 按用途分：连接螺纹（普通螺纹、管螺纹）要能自锁、不松；传动螺纹（梯形、锯齿形）要效率高、能承受大的轴向力。
  • 名词和代号按 GB/T 14791《螺纹 术语》，普通螺纹的基本牙型按 GB/T 192（ISO 68-1）。
把一个直角三角形卷到圆柱上，斜边就是螺旋线。牙型沿着螺旋线扫过去，就是螺纹。

01牙型与牙型角 α

沿轴线剖开看到的牙齿形状
  • 牙型角 α：轴向截面里相邻两个牙侧之间的夹角。牙侧角 β：一个牙侧和垂直于轴线的径向线的夹角。对称牙型 β = α/2；锯齿形、骨钉这类不对称牙型要分别标出两侧的牙侧角。
  • 牙型角越大，牙根越粗，摩擦越大，越容易自锁，适合连接；牙型角越小，效率越高，适合传动。
沿着轴线把螺纹剖开，看到的牙齿形状就是牙型。两个牙侧之间的夹角叫牙型角，普通螺纹是六十度。

02大径、中径、小径

一个螺纹有三个直径
外螺纹的大径 d 是牙顶的直径，也是螺纹的公称直径（M12 的 12）；小径 d1 在牙底；中径 d2 是一个假想的圆柱，在它上面牙宽和槽宽正好相等，各占半个螺距。右边是放大的牙型。
  • 内螺纹用大写字母：D、D2、D1。内外螺纹的基本尺寸相同，靠公差留出间隙。
  • 中径决定了牙侧在哪里接触，是螺纹配合最关键的尺寸，公差最严，三针法、螺纹千分尺量的都是它。
  • 普通外螺纹实际的牙底是圆弧，牙底直径叫 d3，比 d1 还小一点，计算螺栓强度时用它。
螺纹有三个直径：牙顶是大径，牙底是小径，中间那个牙宽和槽宽一样大的地方，叫中径。

03螺距 P、线数 n、导程 Ph

相邻两个牙的距离，和拧一圈走多远
螺距 P 是相邻两个牙之间的轴向距离；导程 Ph 是同一条螺纹绕一圈前进的距离。只有一条螺纹（单线）时两者相等；绕了 n 条（多线），转一圈就前进 n 个螺距。图中三根螺杆螺距相同，橙色箭头跟着同一条螺纹走一圈。
  • Ph = n P。多线螺纹拧得快，适合需要快速移动的地方，如瓶盖、笔帽、快速丝杠。
  • 多线普通螺纹的标记：M16 × Ph3P1.5（导程 3，螺距 1.5，双线）；梯形螺纹：Tr40 × 14(P7)。
  • 同一个直径有粗牙和细牙：粗牙螺距标准化、不用标（M12 就是 P1.75）；细牙必须标出螺距（M12×1.5）。
螺距是相邻两个牙的距离，导程是拧一圈走多远。单线螺纹两者一样；双线螺纹拧一圈走两个螺距。

04旋向：右旋和左旋

竖起来看，牙往哪边升
把螺杆竖起来看正面：螺纹从左下往右上升的是右旋，从右下往左上升的是左旋。也可以用手比：右旋螺纹顺着右手四指弯曲的方向拧，螺杆就朝大拇指方向前进——顺时针拧紧。
  • 绝大多数螺纹是右旋，右旋不标；左旋要标 LH，如 M24 × 1.5 − LH。
  • 左旋用在转动会把右旋螺纹带松的地方：自行车左脚踏、砂轮左侧压紧螺母；也用来防止误接，如燃气瓶阀；花篮螺栓一头右旋一头左旋，转一下两头一起收紧。
  • 蜗杆、滚刀、斜齿轮的“旋向”也是同样的看法。
把螺杆竖起来，螺纹往右上升就是右旋，往左上升就是左旋。平时用的几乎都是右旋，顺时针拧紧。

05导程角 φ

螺旋线有多“陡”
把中径圆柱展开：底边是 π d2，高是导程 Ph，斜边和底边的夹角就是导程角（也叫螺纹升角）。图中三角形按真实比例画——普通粗牙螺纹的导程角只有约 2°～3.5°，几乎是平的。
  • tan φ = Ph / (π d2) = n P / (π d2)。导程越大、直径越小，导程角越大。
  • 导程角决定了螺纹能不能自锁和传动效率（10 节）；车削螺纹时，车刀两侧的后角也要按导程角修正。
  • 骨钉直径小、螺距大，导程角明显大；多线梯形螺纹的导程角能到 7° 以上。
导程角就是螺旋线的坡度。普通螺纹的坡度很小，只有两三度，所以拧紧以后不会自己松开。

06普通螺纹的基本牙型（GB/T 192 / ISO 68-1）

从一个等边三角形削出来
普通螺纹的牙型来自一个高 H = (√3/2) P = 0.866025 P 的原始三角形（虚线）：顶部削去 H/8 成为宽 P/8 的平顶，底部削去 H/4 成为宽 P/4 的平底。螺母（上）和螺栓（下）共用这条基本牙型线，实际尺寸再按公差往里收。
  • d2 = d − 0.649519 P（= d − 3H/4），d1 = d − 1.082532 P（= d − 5H/4）。
  • 外螺纹牙底做成圆弧（虚线），牙底直径 d3 = d − 1.226869 P，圆弧半径 R = H/6 ≈ 0.144 P；外螺纹理论牙高 (d − d3)/2 = 0.6134 P，也就是车外螺纹的总切深。
  • 直径与螺距系列按 GB/T 193，基本尺寸按 GB/T 196。
普通螺纹的牙型是一个等边三角形削平了尖顶和尖底。中径离大径四分之三个三角形高，小径离大径八分之五个。

07公差带与标记

M12×1.5-5g6g-S-LH 每一段是什么意思
螺纹标记按“牙型和直径 × 螺距 − 公差带 − 旋合长度 − 旋向”的顺序写。公差带由公差等级（数字，越小越精密）和基本偏差（字母，决定公差带离基本尺寸多远）组成：外螺纹用小写 e、f、g、h，内螺纹用大写 G、H。
  • 最常用的配合是 6H / 6g：螺母 6H 从基本尺寸往大里放（下偏差 0）；螺栓 6g 从基本尺寸往小里收，留出一点间隙 es：按 GB/T 197 表 1 取值，如 P1.5 为 −32 μm、P1.75 为 −34 μm（由公式 −(15 + 11P) 圆整而来，以表为准），方便装配和镀层。
  • 公差带写两个时，前面是中径、后面是顶径（外螺纹顶径是大径，内螺纹顶径是小径），两个一样只写一个：M10 − 6g。
  • 旋合长度 S（短）、N（中等，不标）、L（长）；中等精度、中等旋合长度最常用。标准：GB/T 197（ISO 965-1）。
螺纹标记从左往右读：什么螺纹、多粗、螺距多大、什么公差、旋合多长、左旋还是右旋。

08管螺纹：密封靠什么

55° 管螺纹分圆柱的和圆锥的
G 是圆柱管螺纹（55° 非密封，GB/T 7307 / ISO 228-1），螺纹本身不密封，要靠端面的垫圈或密封圈；R、Rc、Rp 是 55° 密封管螺纹（GB/T 7306 / ISO 7-1），外螺纹做成 1:16 的圆锥，越拧越紧，螺纹之间缠上生料带或涂密封胶就能密封。
  • R₁ 外锥螺纹配 Rp 内圆柱螺纹（GB/T 7306.1）；R₂ 外锥螺纹配 Rc 内锥螺纹（GB/T 7306.2）。
  • 尺寸代号是管子的英寸通径，不是螺纹大径：G1/2 每英寸 14 牙（P = 1.814），大径 20.955 mm。
  • 美国的 NPT 是 60°、1:16 锥度（ASME B1.20.1），和 55° 的 R 不能互换。
G 管螺纹是圆柱的，靠垫圈密封；R 管螺纹是一比十六的圆锥，越拧越紧，螺纹自己就能密封。

09传动螺纹和骨钉螺纹

为什么牙型要做成不对称的
传力方向决定牙型：梯形螺纹两面都是 15°，正反都能推；锯齿形螺纹把受力的一面做成几乎垂直（3°），推力几乎全沿轴向传递、效率高，另一面 30° 让牙根更粗；骨钉也是这个思路——朝钉头的一面接近垂直，专门抵抗拔出力。
  • 梯形 Tr（GB/T 5796）：d2 = d − 0.5P，牙高 h3 = 0.5P + ac，牙顶间隙 ac 按螺距取 0.15、0.25、0.5、1 mm。用于机床丝杠、台钳、阀杆。
  • 锯齿形 B（GB/T 13576）：h3 = 0.867767P，牙底整圆弧 R = 0.124271P。用于压力机、千斤顶、大口径管道快速接头。
  • 骨钉（ISO 5835 / ASTM F543）：HA 用于皮质骨，牙侧 35°/3°，螺距小、牙浅；HB 用于松质骨，25°/5°，螺距大、牙深，抓得更牢。35°（25°）一面朝钉尖，方便拧入；3°（5°）一面朝钉头，承受拔出力。
梯形螺纹两边都能推；锯齿形和骨钉只有一边是“陡壁”，专门用来扛单方向的大力。

10自锁与效率

导程角小于摩擦角，螺母就不会自己转回去
拧螺母就像把重物推上斜面：斜面的坡度是导程角 φ。牙侧是斜的，压在牙侧上的力被放大，所以螺纹的摩擦比平面大，叫当量摩擦角 ρ′ = arctan(μ / cos β)。只要 φ ≤ ρ′，松手后螺母不会自己转回来——自锁。
  • 拧紧（推上斜面）的效率 η = tan φ / tan(φ + ρ′)。普通螺纹只有 10%～30%：拧紧力矩里大约一半耗在螺母（或螺钉头）端面的摩擦上，四成耗在螺纹摩擦上，只有一成左右变成预紧力。
  • 连接螺纹要自锁，所以用牙型角大的三角形螺纹、单线、细牙；传动螺纹要效率，所以用梯形、锯齿形、多线，或者干脆用滚珠丝杠（滚动摩擦，效率 90% 以上，不能自锁）。
  • 振动、冲击、温度变化会让自锁失效，重要的连接要加防松：弹簧垫圈、双螺母、开口销、螺纹胶等。
导程角比摩擦角小，螺纹就能自锁，拧上以后不会自己松开。但能自锁的螺纹，效率都不高。

11怎么加工

车、搓、滚、铣、磨，内螺纹还可以攻丝

车螺纹的三种进刀方式（每种分 6 刀，每刀切深按 √k 递减，切屑面积大致相等）：

滚压螺纹：毛坯直径约等于中径，滚丝轮把槽里的金属挤到牙顶上，金属纤维不被切断。

  • 车削：工件转一圈，车刀沿轴向走一个导程，分多刀车到全牙深（普通外螺纹 0.6134P）。直进法两刃同时切，适合小螺距；斜进法（沿牙侧方向进刀，进刀角比牙侧角小 0.5°～5°，刀具厂常推荐小 1° 左右）排屑好，适合大螺距和难加工材料；左右交替进刀两侧刃磨损均匀，适合梯形螺纹。
  • 攻丝 / 套丝：丝锥加工内螺纹，板牙加工外螺纹，单件和小直径最方便。
  • 滚压（搓丝）：冷挤压成形，生产率高，螺纹表面硬化、纤维连续，疲劳强度高，标准螺栓大多是滚出来的。
  • 旋风铣：几把刀装在高速旋转的刀盘上，刀盘偏心绕工件转，一次走刀铣出全牙型。走心机上加工骨钉、长丝杠常用。
  • 螺纹铣削（数控螺旋插补，适合大直径内螺纹）和螺纹磨削（单线、多线砂轮，用于淬硬的精密丝杠、螺纹量规）。
螺纹可以车出来、攻出来、滚出来、铣出来，也可以磨出来。标准螺栓大多是滚出来的，强度更高。

12怎么检测

量规判合格，三针量中径
生产中最常用螺纹量规：通规（GO）要能顺利拧进去，止规（NO GO）最多拧进两圈，就判合格。要知道具体尺寸，用三针法：三根直径相同的量针放进牙槽（一边一根、另一边两根），量针外侧的距离 M 反算出中径。拖动滑块看量针和牙侧的接触点：最佳量针正好在中径线上接触，牙型角误差对结果影响最小。
  • 通用公式（对称牙型）：M = d2 + dw(1 + 1/sin(α/2)) − (P/2) cot(α/2)；最佳量针 dw = P / (2 cos(α/2))。
  • 60°：M = d2 + 3dw − 0.866025P，最佳 0.57735P；55°：M = d2 + 3.1657dw − 0.9605P；30°：M = d2 + 4.8637dw − 1.8660P。导程角大时还要做导程角修正。
  • 其他方法：螺纹千分尺（一头锥形、一头 V 形测头）直接量中径；工具显微镜、轮廓仪、影像仪量牙型角、螺距和牙底圆角，骨钉这类不对称牙型多用光学或轮廓测量。
螺纹合不合格，用通规止规一拧就知道；要量具体尺寸，就用三根量针量中径。

13动手试一试

选牙型和规格，算出各个直径、导程角、量针和效率
选好牙型和规格，中径、小径、牙高、导程角、最佳量针和三针读数，还有能不能自锁，一下子都出来了。
