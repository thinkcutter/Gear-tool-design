外齿还是内齿？看参数就知道

齿轮、花键的参数表上，哪几项能告诉你它是外齿还是内齿。一张图一个判断方法。

00外齿和内齿长什么样

牙朝外长的是外齿，牙朝里长的是内齿
外齿轮、外花键的牙长在外圆上，像一根带齿的轴；内齿轮、内花键的牙长在内孔里，像一个带齿的套。两者的牙尖方向正好相反：外齿的齿顶朝外，内齿的齿顶朝向圆心。
同样是齿，有的长在轴上朝外，有的长在孔里朝里。拿到一张参数表，怎么判断是哪一种？

01最快的判断：齿顶圆和齿根圆谁大

外齿：齿顶圆 > 齿根圆；内齿：齿顶圆 < 齿根圆
外齿轮：da > d > df；内齿轮：da < d < df。
只要参数表上同时有齿顶圆和齿根圆，齿顶圆比齿根圆小，就是内齿。
注意：按 DIN 3960 / ISO 21771-1 写法，内齿轮直径带负号（如 da = −174、df = −187.5），要按绝对值比较；直径带负号本身就说明是内齿轮。
最快的办法，是比较齿顶圆和齿根圆。外齿的齿顶圆最大，内齿的齿顶圆反而最小。

02“大径、小径”本身分不出内外

大径永远比小径大，关键是它对应齿顶还是齿根
齿顶圆齿根圆
外齿轮 / 外花键大径（外圆）小径
内齿轮 / 内花键小径（内孔）大径
花键图纸常常只写“大径、小径”。这时要看直径符号或者下一节的标记，不能只凭名字判断。
注意，大径、小径这两个名字分不出内外。外齿的大径是齿顶，内齿的大径是齿根。

03直径符号：看第二个下标

GB/T 3478.1 / ISO 4156 渐开线花键
符号含义属于
Dee大径外花键
Die小径外花键
Dei大径内花键
Dii小径内花键
第一个下标说是大径（e）还是小径（i），第二个下标说是外花键（e）还是内花键（i）。
花键的直径符号有两个下标，看第二个：e 是外花键，i 是内花键。

04标记：EXT / INT，大写和小写

和孔轴配合同一个规则：孔用大写，轴用小写
  • 渐开线花键（GB/T 3478.1）
    外花键：EXT 24z×2.5m×30R×5h
    内花键：INT 24z×2.5m×30P×5H
  • 矩形花键（GB/T 1144）
    外花键：6×23f7×26a11×6d10
    内花键：6×23H7×26H10×6H11
渐开线花键看前缀：EXT 是外花键，INT 是内花键（30R 为圆齿根，30P 为平齿根）。
矩形花键看公差代号：小写是外花键，大写是内花键。
德标 DIN 5480 花键看字母：W（Welle，轴）是外花键，N（Nabe，毂）是内花键，例如 DIN 5480 W 50×2×24×8h / DIN 5480 N 50×2×24×9H，公差代号同样是外小写、内大写。
标记最直接：EXT 是外，INT 是内。公差代号也一样，小写是轴，大写是孔。

05齿数和中心距的正负

DIN 3960 / ISO 21771-1：内齿轮齿数写成负数
德标和 ISO 的写法里，内齿轮的齿数是负数（比如 z = −36）。这样外啮合、内啮合可以用同一个公式：a = m(z1+z2)/2。
外啮合 a = m(18+36)/2；内啮合 a = m(18−36)/2，算出来是负的，绝对值就是两个分度圆半径之差。
德标和 ISO 图纸上，齿数前面有负号，就是内齿轮。内啮合的中心距是两个半径相减。

06测量方式：跨棒距还是棒间距

外齿在量棒外面量，内齿在量棒中间量
  • 跨棒距（Dimension over pins / balls）：两根量棒放进齿槽，从外面卡 → 外齿
  • 棒间距（Dimension between pins / balls）：两根量棒放进齿槽，在中间量 → 内齿
  • 公法线长度 Wk：跨几个齿夹住齿面 → 一般只有外齿有
再看测量项：写跨棒距和公法线的，是外齿；写棒间距的，是内齿。

07控制的是齿厚还是齿槽宽

外齿管“牙有多胖”，内齿管“槽有多宽”
外齿轮、外花键的公差控制齿厚 s（花键叫实际齿厚、作用齿厚）；内齿轮、内花键常控制齿槽宽 e（花键叫实际齿槽宽 E、作用齿槽宽）。参数表上出现“齿槽宽”，一般就是内齿。
外齿控制的是齿厚，内齿控制的是齿槽宽。看到齿槽宽，基本就是内齿。

08别用变位系数的正负来判断

各标准对内齿轮变位的符号规定不一样
同一个内齿轮，按 GB 写法和按 DIN 写法，变位系数 x 可能正负相反。之前做过的一件 M1 Z10 内花键，图纸上 x 为 +0.4616，计算时要换成 −0.4616 才和量棒距对得上。x 的符号只能用来计算，不能用来判断内外。
变位系数的正负，各个标准规定不一样，不能拿来判断内外。

09判断顺序

三步，一般三项都对得上
三项都对得上，就可以放心。如果互相矛盾，多半是图纸写错了，要和客户确认，不要自己猜。
先看标记，再比齿顶圆和齿根圆，最后看测量方式。对不上，就找客户确认。
