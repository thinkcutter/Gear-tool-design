蜗杆参数图解

头数、轴向模数、导程角、直径系数、齿形、变位、效率和自锁……一张图一个参数，看动画就懂。

00蜗杆传动是怎么回事

一根“螺杆”拧着一个齿轮转，两根轴空间交错 90°
把蜗杆想成一根粗螺丝，蜗轮是被它“拧”着走的齿轮：蜗杆转一圈，螺纹向前推过一个导程，蜗轮就被推着转过 z1 个齿。所以一级就能减速 10～80 倍，而且运转平稳、噪声小。
  • 两根轴在空间里交错（最常见是 90°），既不相交也不平行。图中蜗轮的轴线垂直于纸面。
  • 一般蜗杆主动、蜗轮从动；导程角很小时，反过来用蜗轮推蜗杆推不动，这叫自锁（08 节）。
  • 两齿面之间是大量滑动，所以发热多、效率比齿轮低；蜗轮通常用锡青铜做，蜗杆用钢淬硬后磨削。
  • 常见用途：减速机、分度头和数控转台、升降机构、阀门执行器、卷扬机。
蜗杆就像一根螺丝，蜗轮就像被它拧着走的齿轮。蜗杆转一圈，蜗轮只转过一两个齿，所以减速特别大。

01头数 z1 与传动比 i

一根蜗杆上绕了几条螺纹
头数就是蜗杆上并排绕着几条螺纹，像麻花绳有几股。图中每条螺纹用一种颜色：单头只有一条，双头两条，四头四条。三根蜗杆的齿距一样，转一圈时，橙色箭头跟着同一条螺纹走——单头走 1 个齿距，四头走 4 个齿距。
  • 传动比 i = n1 / n2 = z2 / z1：蜗杆转一圈，蜗轮转过 z1 个齿。注意它不等于直径比 d2/d1，这一点和齿轮不同。
  • 头数常取 1、2、4（也有 6）。头数少，传动比大、容易自锁，但效率低；头数多，效率高，但导程角大、蜗杆不好加工。
  • 蜗轮齿数 z2 一般取 28～80：太少啮合区小，容易根切；太多蜗轮太大，蜗杆跨度长、刚度不够。
  • 常用传动比 5、7.5、10、12.5、15、20、25、30、40、50、60、70、80，其中 10、20、40、80 为基本传动比，优先选用。
头数就是蜗杆上绕了几条螺纹。蜗杆转一圈，蜗轮就转过几个齿，所以传动比等于蜗轮齿数除以蜗杆头数。

02轴向模数 mx 与轴向齿距 px

在中间平面里，蜗杆就是一根齿条
用一个平面沿蜗杆轴线、垂直于蜗轮轴线切开，这个平面叫中间平面。在这个平面里，蜗杆的齿形（橙色线）就是一根齿条，蜗轮就是和它啮合的齿轮——所以蜗杆的参数都在轴向定义，蜗轮的参数都在端面定义。
  • 正确啮合条件：mx1 = mt2 = m，αx1 = αt2 = α，并且蜗杆导程角等于蜗轮螺旋角 γ = β2、旋向相同。
  • 轴向齿距 px = π m：相邻两个牙在轴线方向上的距离，在分度圆柱上量，牙厚和槽宽相等，各为 π m / 2。
  • 蜗杆模数按 GB/T 10088 取，常用 1、1.25、1.6、2、2.5、3.15、4、5、6.3、8、10、12.5、16、20、25……注意 3.15、6.3 和齿轮模数系列（3、6）不一样。
顺着蜗杆的轴线切一刀，蜗杆的齿形就是一根齿条，蜗轮就是和它啮合的齿轮。所以蜗杆的模数叫轴向模数。

03导程 pz 与导程角 γ

把分度圆柱展开，螺旋线就是一条斜线
头数 z₁：
把蜗杆的分度圆柱像纸筒一样剪开铺平：一圈的周长是 π d1，同一条螺纹绕一圈沿轴向前进一个导程 pz = z1 px，螺旋线就变成直角三角形的斜边。斜边和圆周方向的夹角就是导程角 γ。
  • tan γ = pz / (π d1) = z1 m / d1 = z1 / q。头数越多、蜗杆越细，导程角越大。
  • 导程角决定了效率和能不能自锁：能否自锁要看 γ 是否小于当量摩擦角（08 节），GB/T 10085 的蜗杆参数表把 γ < 3°30′ 的蜗杆标为自锁；要效率时取 15°～30°。
  • 蜗杆的导程角 γ 和螺旋角 β1 互余：β1 = 90° − γ；而蜗轮的螺旋角 β2 = γ。
把分度圆柱剪开铺平，螺旋线就是一条斜线。斜线越陡，导程角越大，蜗杆越“快”，但也越不容易自锁。

04分度圆直径 d1 与直径系数 q

同一个模数，蜗杆可以粗也可以细——但要按标准选
齿轮的分度圆直径由齿数决定（d = m z），蜗杆却不行：同样模数、同样头数，蜗杆可以做粗，也可以做细。图中两根蜗杆都是 m = 4、z1 = 2，细的 d1 = 40，粗的 d1 = 71，螺纹的倾斜程度（导程角）明显不同。
  • 直径系数 q = d1 / m，所以 d1 = q m。
  • 为什么要标准化？蜗轮是用和蜗杆一模一样的滚刀切出来的，蜗杆直径每多一种，就要多备一把滚刀。所以 GB/T 10088 / GB/T 10085 对每个模数只规定了少数几个 d1（例如 m = 4：40、71；表 1 里还有带括号的 31.5、50，标准注明括号中的数字尽可能不采用）。
  • 细蜗杆导程角大、效率高，但刚度差、容易弯；粗蜗杆刚度好但效率低。传递功率时按 GB/T 10085 的匹配表选 m、d1、z1。
蜗杆的粗细不由齿数决定，而是标准里规定好的几种。因为每一种粗细都要配一把专门的滚刀去切蜗轮。

05齿形：ZA、ZN、ZI、ZK、ZC

齿面在哪个截面里是直线——取决于刀具怎么放

左：侧视图和刀具位置（橙色为齿面是直线的截面）；右：端面（垂直于轴线的截面）里的齿形，双头蜗杆。

  • GB/T 10087 规定基本蜗杆的齿形角：ZA 为轴向齿形角 αx = 20°；ZN、ZI 为法向齿形角 αn = 20°；ZK 为形成齿面的锥形刀具的产形角 α0 = 20°。动力传动中导程角 γ > 20° 时允许增大齿形角，推荐 25°；分度传动允许减小，推荐 15° 或 12°。本页计算一律按 20°。
  • GB/T 10085 推荐采用 ZI 和 ZK 蜗杆；除特殊要求外，蜗杆用右旋。ZC 蜗杆的齿形和其他几种不同，齿顶圆、齿根圆要另行计算。
  • 蜗轮必须用和配对蜗杆同一种齿形的滚刀加工，否则啮合不对。
五种蜗杆长得差不多，区别在于车刀或砂轮放在什么位置，所以齿面在哪个截面里是直线也不一样。

06齿顶圆、齿根圆和基本齿廓

在轴向截面里规定牙有多高、多厚
GB/T 10087 在蜗杆的轴向截面里规定了基本齿廓：牙高出分度线 1 个模数，往下挖 1.2 个模数，多出的 0.2 个模数就是留给蜗轮齿顶的顶隙。图中虚线是蜗轮的齿，它插进蜗杆的齿槽，底下留一条缝。
  • 齿顶高 ha = 1 m，工作齿高 h′ = 2 m；采用短齿时 ha = 0.8 m、h′ = 1.6 m。
  • 顶隙 c = 0.2 m，必要时允许 0.15m～0.35m；齿根圆角 ρf = 0.3 m，必要时允许 0.2m～0.4m，也可做成单圆弧；齿顶允许倒圆，半径不大于 0.2m。
  • 齿顶圆 da1 = d1 + 2 m，齿根圆 df1 = d1 − 2.4 m（按 c = 0.2m）。
  • 分度圆上轴向齿厚 = 齿槽宽 = π m / 2；法向齿厚约 sn = (π m / 2) cos γ。
蜗杆的牙高出分度线一个模数，往下挖一点二个模数，下面留出零点二个模数的顶隙给蜗轮的齿顶。

07蜗轮：分度圆 d2、变位 x2 与中心距 a

只给蜗轮变位，蜗杆永远不变
蜗轮分度圆 d2 = m z2。要凑一个整数中心距，或者改一点传动比，就给蜗轮变位：滚刀（也就是蜗杆）离蜗轮远一点或近一点。蜗杆尺寸不变，只是它和蜗轮相切的那条线（节线）离开了分度线 x2 m。右图是侧视：蜗轮齿顶做成凹圆弧（喉部），把蜗杆“抱”住。
  • 中心距 a = (d1 + d2 + 2 x2 m) / 2；标准中心距优先取 40、50、63、80、100、125、160、200、250、315、400、500。
  • 蜗轮喉圆 da2 = d2 + 2m(1 + x2)，齿根圆 df2 = d2 − 2m(1.2 − x2)，喉母圆半径 rg2 = a − da2/2。
  • 蜗轮外径和宽度常用经验值：de2 ≤ da2 + 2m（单头）、+1.5m（2～3 头）、+m（4 头）；b2 ≤ 0.75 da1（≤3 头）、0.67 da1（4～6 头）。
  • 变位系数一般在 −1～+1 之间，常用 −0.5～+0.5；变位后蜗轮齿厚变化，蜗轮滚刀不用换。
蜗杆从来不变位，只给蜗轮变位。变位以后，蜗杆的节线离开分度线，中心距跟着变。

08效率与自锁

斜面越平越省力，但也越容易“卡住不动”
蜗杆推蜗轮就像沿斜面推箱子：导程角就是斜面的坡度。坡太平，推的力大部分耗在摩擦上，效率低；反过来想让箱子自己滑下来（蜗轮推蜗杆），如果坡度小于摩擦角，它根本滑不动——这就是自锁。
  • 蜗杆主动时啮合效率 η1 = tan γ / tan(γ + ρv)；蜗轮主动时 η′ = tan(γ − ρv) / tan γ。当量摩擦角 ρv = arctan f′。
  • γ ≤ ρv 时 η′ ≤ 0，蜗轮推不动蜗杆，即自锁；此时蜗杆主动的效率也低于 50%。
  • f′ 随滑动速度、材料和润滑变化，钢蜗杆配锡青铜蜗轮一般在 0.02～0.1 之间，滑动速度越高、润滑越好，f′ 越小。
  • 总效率还要乘上轴承和搅油损失（约 0.95～0.96）。粗略估计：单头 0.70～0.75，双头 0.75～0.82，四头 0.87～0.92。
  • 注意：振动、冲击会让自锁失效，起重、升降等安全场合不能只靠蜗杆自锁，必须另加制动器。
导程角就是斜面的坡度。坡太平，蜗轮就推不动蜗杆，这叫自锁；但自锁的蜗杆，效率一定不到一半。

09齿面滑动速度 vs

蜗杆的齿面是“擦”着蜗轮走的
在节点处，蜗杆表面的速度 v1 沿圆周方向，蜗轮的速度 v2 沿蜗杆轴线方向，两者互相垂直，差别全靠齿面之间沿螺纹方向滑过去。滑动速度 vs 比 v1 还大。
  • vs = v1 / cos γ = √(v1² + v2²)，v2 = v1 tan γ，v1 = π d1 n1 / 60000（m/s，d 用 mm）。
  • 滑动速度高，发热大、容易胶合和磨损，所以蜗轮用减摩的锡青铜（如 ZCuSn10P1），蜗杆淬硬磨光，并要充分润滑、散热。
  • 滑动速度也是选材料、选润滑油和查当量摩擦系数 f′ 的依据。
蜗杆的齿面不是滚过蜗轮，而是擦过蜗轮。滑动速度比蜗杆表面的线速度还大，所以蜗杆传动特别怕发热。

10怎么加工

蜗杆像车螺纹一样车出来，蜗轮用“蜗杆”去滚出来

车蜗杆：工件转一圈，车刀沿轴向走一个导程，左边已车出螺纹，右边还是毛坯。

滚蜗轮：滚刀（开了容屑槽的“蜗杆”）和蜗轮按传动比一起转，同时径向切入到中心距。

车蜗杆和车螺纹一样，工件转一圈，车刀沿轴向走一个导程 pz，分多刀车到全齿深。滚蜗轮的滚刀就是一根开了容屑槽、磨出后角的蜗杆，它和蜗轮按真实的传动比一起转，同时径向逐渐切入到中心距 a。
  • 蜗杆：ZA 用直线刃车刀、刀刃对准中心车削；ZN 车刀转过导程角；ZI 可用平面砂轮磨削；ZK 用盘铣刀铣削、锥面砂轮磨削；ZC 用凸圆弧砂轮磨削。长蜗杆也常用旋风铣。动力蜗杆一般淬硬后磨削。
  • 蜗轮：用蜗轮滚刀在滚齿机上滚切，可以径向进给，也可以切向进给（多头、大导程角时更好）；单件小批也可以用飞刀（单齿刀）切向展成。
  • 蜗轮滚刀的模数、分度圆直径、头数、齿形角、齿形类型和旋向都必须和蜗杆一致，齿顶比蜗杆高出一个顶隙，用来切出蜗轮的齿根。
  • 装配后在蜗杆齿面涂色，转动检查蜗轮上的接触斑点：位置和大小按 GB/T 10089 的要求，不合格就调整蜗轮的轴向位置。
蜗杆像车螺纹一样车出来，蜗轮则用一把和蜗杆一模一样的滚刀滚出来，所以蜗杆和滚刀的参数必须完全一致。

11怎么检测

量棒法量中径，齿厚卡尺量牙厚
把三根直径相同的量棒放进蜗杆的齿槽（一边一根，另一边两根），用千分尺量棒外侧的距离 M，就能算出分度圆上的齿厚对不对。量棒直径取得刚好在分度线附近接触齿面（最佳量棒），测量结果受齿形角误差影响最小。
  • ZA 蜗杆（轴向直廓）：M = d1 + dp(1 + 1/sin αx) − (px/2) cot αx，最佳量棒 dp = px / (2 cos αx) ≈ 1.672 m，此时 M ≈ d1 + 2.243 m。导程角大时，量棒在齿槽里是斜着贴的，要按标准或手册做修正；ZN、ZI、ZK 齿形的轴向截面不是直线，也要用各自的公式。
  • 也可以用齿厚游标卡尺在法向量弦齿厚：卡尺高度对准齿顶以下 ha = m，量 sn ≈ (π m / 2) cos γ。
  • 精密蜗杆在齿轮测量中心或蜗杆测量仪上测齿廓、导程（螺旋线）和齿距偏差；蜗轮测齿距、径向跳动，也可以和标准蜗杆做双面啮合综合检测。精度等级按 GB/T 10089（1～12 级）。
量棒放进齿槽，量棒外面量出一个尺寸，就能反算出齿厚。这和测螺纹中径用的是同一个办法。

12动手试一试

选模数和蜗杆直径，看蜗杆副的尺寸和效率怎么变
模数和蜗杆直径按标准选，头数决定导程角，蜗轮齿数决定传动比，变位调中心距，摩擦系数决定效率和能不能自锁。
