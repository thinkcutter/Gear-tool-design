图纸上没有的参数怎么填

变位系数 x没有就填 0。已填齿顶圆、齿根圆和跨棒距时，x 只轻微影响齿根过渡曲线。
齿顶高系数 ha* / 顶隙系数 c*标准齿轮填 1 / 0.25。填了齿顶圆、齿根圆后会自动代替。
齿根圆角系数 ρf*齿轮一般 0.38；花键按所选齿根类型自动给出。图纸有渐开线起始圆时，以程序检查“合格”为准，可适当加大，让刀尖更结实。
齿厚减薄 Δs图纸给了跨棒距、公法线或齿厚时，在“齿厚依据”里选对应的一种，Δs 自动计算；都没有就填 0，即理论齿厚。
齿根圆公差齿根圆由铣刀刀尖决定，有公差时填公差中值，例如 Φ237.5(0/−0.46) 填 237.27。齿顶圆不由铣刀加工，填公称值即可。
换算英制径节 DP：m = 25.4 / DP。只给导程 L 时：sinβ = π·mn·z / L。只给端面模数 mt 时：mn = mt·cosβ。
带公差的直径齿顶圆、齿根圆、检测尺寸可以照图纸写：944H7、237.5 0 -0.46、1400.68-1401.19、930.347 +0.262 0，程序自动换算并取中值。
图纸上的“齿轮参数”指外齿轮，选“外齿轮”；“内齿轮参数”选“内齿轮”，它的“跨棒距”实际是棒间距。
内花键在“渐开线花键”里选“内花键”。GB/T 3478.1 内花键的小径按 DFe max + 2cF、大径按 m(z + 2×齿根高系数) 自动计算，公差按 H；图纸给了小径、大径就照填。DIN 5480 内花键的变位按 DIN（齿数取负）的符号，图纸上一般是负值。
DIN 5480 花键压力角选“DIN 5480”。图纸上的“移距量”是 x·m（毫米），变位系数 x = 移距量 ÷ 模数。
精度等级不参与刀具廓形计算，只决定零件的公差大小。齿轮可以在“精度等级换算”里算出具体公差，并据此给出刀具廓形公差建议。
齿根形式一般选“展成”；图纸标注了齿根圆弧半径时选“切圆弧”。
旋向 / 齿宽旋向只改变 3D 里螺旋的方向，齿宽只影响 3D 显示，都不影响刀具廓形。
刀具设置、倒角、修缘、留磨量按你们的加工工艺填写；没有要求就保持默认值 0。

互相关联的参数

齿顶圆 da ↔ 齿顶高系数填了 da，花键的齿顶高系数由 da 推算并锁定。
齿根圆 df ↔ 顶隙系数 / 齿根高系数填了 df，齿轮的 c*、花键的齿根高系数由 df 推算并锁定。
跨棒距 / 公法线 / 齿厚 ↔ 齿厚减薄三种齿厚依据只能选一种。选定并填写后，齿厚减薄由它推算并锁定。
压力角 / 齿根类型（花键）选择后自动填好标准的齿顶高、齿根高和圆角系数，之后可以再改。

每个重要参数的标签后面有一个“?”，点一下可以看到这个参数的含义和图纸上没有时的填法。被代替的参数会变成橙色虚线框，标签后注明“由 … 推算”，框内显示推算出的值。把图纸值改回 0 就恢复手动输入。

计算方法

外齿轮 / 渐开线花键：用基本齿条（含齿顶圆角）在端面内展成，得到渐开线 + 齿根过渡曲线；有根切时自动去掉自交环，与实际滚齿齿形一致。也可选“切圆弧”齿根。内齿轮为渐开线 + 与根圆相切的过渡圆弧；矩形花键为平行键侧 + 小径圆角。

插刀后角形式与廓形补偿：① 整体倾斜：刀具做成等截面棱柱，装刀时倾斜 α 得到后角。刀具廓形按后刀面法向截面给出，齿高 × cos(α+γ)/cosγ，宽度不变；侧刃后角随齿侧倾斜变小。② 平面后角：刀具竖直安装，后刀面沿刃口法向磨出（或锥度线切割出）后角 α，侧刃后角处处等于 α。前角 γ = 0 时刃口就是齿槽形状，不需要补偿；γ ≠ 0 时，齿高 H 处的刃口比刀尖靠后 H·tanγ，后刀面在那里已经向内收了 H·tanγ·tanα，所以过刀尖、垂直刀具轴线的基准截面（线切割或磨削编程用）要把齿槽形状沿法向向外放大 H·tanγ·tanα；离基准截面 z 处的截面 = 基准截面沿法向向内收 z·tanα（锥度线切割的另一个面按这个算）。刃口在前刀面内的齿高 = H ÷ cosγ。不考虑重磨。

成形插刀：单齿插刀沿齿向往复插削，切削刃在端面的投影就是齿槽形状，外齿、内齿都适用（只限直齿）。有前角 γ、后角 α 时，刃口在前刀面内的齿高 = 端面齿高 ÷ cosγ；磨刀用的后刀面法向截面齿高 = 端面齿高 × cos(α+γ) ÷ cosγ，宽度方向不变。侧刃的实际后角 = arctan(tanα × sinψ)，ψ 是刃口切线与刀具中心线的夹角，齿侧越接近平行于中心线，侧后角越小，程序会给出最小侧后角。

盘形铣刀：刀轴与齿槽垂直，刀齿廓形就是齿槽的端面形状，槽底按齿根圆铣成圆弧，所以刀齿顶是一段内凹圆弧（结果里的“刀齿顶圆弧凹深”）。只用于直齿外齿轮和花键，坐标表里 X 为刀齿半宽。

直齿：刀轴沿齿槽对称线，刀具轴向廓形 = 端面齿槽廓形。斜齿：刀轴垂直并相交于齿轮轴线，沿螺旋线进给；对每个齿面点求“齿面法线与刀轴相交”的接触点，得到精确的刀具回转廓形。图中虚线为分度圆处的法向截面，供对比。

齿形修正：修缘量从修缘高度起点按直线或抛物线增加，到齿顶达到 Ca；倒角按“高度 × 宽度”给出：高度从齿顶圆沿径向往下量，宽度沿齿顶圆从原齿顶角往齿中间量，两腿相等即 C 型倒角；倒圆为与齿面、齿顶圆同时相切的圆弧。留磨量沿齿面法向把刀具每侧收窄 q，只影响刀具，图中黑线仍是成品齿形；挖根量让刀具在齿根过渡区比成品多铣 pr，磨齿时砂轮不碰齿根、不留台阶，过渡区内两者平滑衔接。斜齿时以上修正都按端面截面计算。

图纸核对：程序把图纸上的齿顶圆、齿根圆和按标准公式（齿轮 ha*、c*、变位；花键按 GB/T 3478.1 或 DIN 5480 齿形）算出的值对比，在结果里列出差值。外齿齿顶圆偏大、齿根偏浅（内齿反过来）这类有干涉风险的偏差会提示向客户确认；齿根更深、齿顶缩短这类常见设计只列出不报警。程序计算一律以图纸数据为准，核对结果只作提醒。

花键没有检测数据时：在“精度等级换算”里填公差等级（如 6），程序按 GB/T 3478.1 的实际齿厚（外花键 h）或实际齿槽宽（内花键 H）公差中值设计刀具，不再用理论齿厚。“取值位置”可改为下限或上限。

图纸检测数据：选择齿厚依据（跨棒距、公法线或直接给齿厚）并填写上下限后，程序反算实际齿厚，并自动代替“齿厚减薄”。斜齿奇数齿用量球测量时，跨棒距按常用近似公式计算。一般按公差中值设计新刀；刀具磨损后槽变窄、跨棒距变大，所以也可以取下限，给磨损留出空间。填了渐开线起始圆后，程序会检查渐开线是否从这个圆（外齿）以下开始，齿根圆角越大起始圆越高。齿顶圆、齿根圆可直接按图纸填写，用来代替系数。

指型铣刀轴向进给，槽底只能铣成平底：选“角部到位”时槽底中心比根圆略深（见“槽底中心多铣”），选“中心到根圆”时圆角处会留下少量残留。DXF 可粘贴到文本文件另存为 .dxf，图层 CUTTER 为刀具廓形。
