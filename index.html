图纸上没有的参数怎么填

变位系数 x没有就填 0。已填齿顶圆、齿根圆和跨棒距（或公法线、齿厚）时，x 不影响刀具廓形。
齿顶高系数 ha* / 顶隙系数 c*标准齿轮填 1 / 0.25。填了齿顶圆、齿根圆后会自动代替。
齿根圆角系数 ρf*齿轮一般 0.38；花键按所选齿根类型自动给出。图纸有渐开线起始圆时，以程序检查“合格”为准，可适当加大，让刀尖更结实。
齿厚减薄 Δs图纸给了跨棒距、公法线或齿厚时，在“齿厚依据”里选对应的一种，Δs 自动计算；都没有就填 0，即理论齿厚。
齿根圆公差齿根圆由铣刀刀尖决定，有公差时填公差中值，例如 Φ237.5(0/−0.46) 填 237.27。齿顶圆不由铣刀加工，填公称值即可。
换算英制径节 DP：m = 25.4 / DP。只给导程 L 时：sinβ = π·mn·z / L。只给端面模数 mt 时：mn = mt·cosβ。
带公差的直径齿顶圆、齿根圆、检测尺寸可以照图纸写：944H7、237.5 0 -0.46、1400.68-1401.19、930.347 +0.262 0，程序自动换算并取中值。
图纸上的“齿轮参数”指外齿轮，选“外齿轮”；“内齿轮参数”选“内齿轮”，它的“跨棒距”实际是棒间距。
内花键在“渐开线花键”里选“内花键”。GB/T 3478.1 内花键的小径按 DFe max + 2cF、大径按 m(z + 2×齿根高系数) 自动计算，公差按 H；图纸给了小径、大径就照填。DIN 5480 内花键的变位按 DIN（齿数取负）的符号，图纸上一般是负值。
DIN 5480 花键压力角选“DIN 5480”。图纸上的“移距量”是 x·m（毫米），变位系数 x = 移距量 ÷ 模数。
精度等级不参与刀具廓形计算，只决定零件的公差大小。齿轮可以在“精度等级换算”里算出具体公差，并据此给出刀具廓形公差建议。
齿根形式一般选“展成（滚刀 / 齿条刀）”，即按滚齿形成的齿根过渡曲线；图纸标注了齿根圆弧半径时选“切圆弧”。
旋向 / 齿宽旋向只改变 3D 里螺旋的方向，齿宽只影响 3D 显示，都不影响刀具廓形。
刀具设置、倒角、修缘、留磨量按你们的加工工艺填写；没有要求就保持默认值 0。

互相关联的参数

齿顶圆 da ↔ 齿顶高系数填了 da，花键的齿顶高系数由 da 推算并锁定。
齿根圆 df ↔ 顶隙系数 / 齿根高系数填了 df，齿轮的 c*、花键的齿根高系数由 df 推算并锁定。
跨棒距 / 公法线 / 齿厚 ↔ 齿厚减薄三种齿厚依据只能选一种。选定并填写后，齿厚减薄由它推算并锁定。
压力角 / 齿根类型（花键）选择后自动填好标准的齿顶高、齿根高和圆角系数，之后可以再改。

每个重要参数的标签后面有一个“?”，点一下可以看到这个参数的含义和图纸上没有时的填法。被代替的参数会变成橙色虚线框，标签后注明“由 … 推算”，框内显示推算出的值。把图纸值改回 0 就恢复手动输入。

计算方法

外齿轮 / 渐开线花键：用基本齿条（含齿顶圆角）在端面内展成，得到渐开线 + 齿根过渡曲线；有根切时自动去掉自交环，与实际滚齿齿形一致。也可选“切圆弧”齿根。内齿轮为渐开线 + 与根圆相切的过渡圆弧；矩形花键为平行键侧 + 小径圆角。

插刀后角形式与廓形补偿：① 整体倾斜：刀具做成等截面棱柱，装刀时倾斜 α 得到后角。刀具廓形按后刀面法向截面给出，齿高 × cos(α+γ)/cosγ，宽度不变；侧刃后角随齿侧倾斜变小。② 平面后角：刀具竖直安装，后刀面沿刃口法向磨出（或锥度线切割出）后角 α，侧刃后角处处等于 α。前角 γ = 0 时刃口就是齿槽形状，不需要补偿；γ ≠ 0 时，齿高 H 处的刃口比刀尖靠后 H·tanγ，后刀面在那里已经向内收了 H·tanγ·tanα，所以过刀尖、垂直刀具轴线的基准截面（线切割或磨削编程用）要把齿槽形状沿法向向外放大 H·tanγ·tanα；离基准截面 z 处的截面 = 基准截面沿法向向内收 z·tanα（锥度线切割的另一个面按这个算）。刃口在前刀面内的齿高 = H ÷ cosγ。不考虑重磨。

成形插刀：单齿插刀沿齿向往复插削，切削刃在端面的投影就是齿槽形状，外齿、内齿都适用（只限直齿）。有前角 γ、后角 α 时，刃口在前刀面内的齿高 = 端面齿高 ÷ cosγ；磨刀用的后刀面法向截面齿高 = 端面齿高 × cos(α+γ) ÷ cosγ，宽度方向不变。侧刃的实际后角 = arctan(tanα × sinψ)，ψ 是刃口切线与刀具中心线的夹角，齿侧越接近平行于中心线，侧后角越小，程序会给出最小侧后角。矩形花键这类平行侧壁几乎没有侧后角，要在“侧后角 αs”里另磨 1°–3°（只在刃口后面收窄，不改变刃口形状和廓形）。

圆柄插刀与刀杆检查：3D 按圆柄单齿插刀显示——前端刀头 + 缩颈 + 刀柄，刀具轴线平行于工件轴线，偏心放置使刀尖正好到达齿根圆；动画为切削行程、抬刀回程、刀头退出工件后分度一个齿。内齿（内花键）时缩颈在内孔里，程序按内孔（小径）自动限制缩颈直径，并给出切削时和抬刀回程时缩颈与孔壁的最小间隙；外齿时给出刀柄与零件外圆的间隙。刀柄直径、刀头长度只影响 3D 和干涉检查，不影响刀具廓形。

盘形铣刀：刀轴与齿槽垂直，刀齿廓形就是齿槽的端面形状，槽底按齿根圆铣成圆弧，所以刀齿顶是一段内凹圆弧（结果里的“刀齿顶圆弧凹深”）。坐标表里 X 为刀齿半宽。斜齿：刀盘平面按分度圆螺旋角 β 扳转（刀轴与齿轮轴线成 90° − β），工件边转边移走螺旋线。刀盘与螺旋齿面的接触线是一条空间曲线，不在法向截面内，所以刀齿廓形不等于齿槽法向截面：程序对每个齿形点求“齿面法线与刀轴相交”的接触点（与蜗杆、螺纹盘形铣刀同一方法）得到精确廓形，再把刀盘沿螺旋线扫过工件核对有没有多切。斜齿时廓形与刀盘外径有关，只适用于输入的外径。

蜗杆（ZA / ZN / ZI / ZK，GB/T 10087、DIN 3975）：ZA 轴向截面齿形为直线；ZN 齿槽法向截面为直线（程序迭代法向槽宽，使分度圆轴向齿厚准确）；ZI 端面为渐开线，tanαt = tanαn / sinγ1，基圆 rb = r1·cosαt；ZK 由双锥砂轮（盘铣刀）包络生成，生成刀具直径填在“ZK 生成刀具直径”里。齿根圆角在各自的定义截面里做。

蜗轮开粗：精加工蜗轮要用与配对蜗杆一致的滚刀或飞刀展成，成形铣刀只用于开粗。程序把滚刀看成配对蜗杆（齿顶加高一个顶隙、齿顶按“滚刀齿顶圆角系数”倒圆），在平行于中间平面的 25 个截面里分别求出滚刀包络出的真实齿槽（每个截面里滚刀的截形像一根齿条，与蜗轮按传动比滚动），取所有截面齿槽的公共部分，再沿齿面法向减去余量，得到开粗齿槽，然后按螺旋线走刀计算指型铣刀或盘形铣刀。蜗轮槽底是一段圆弧，两端比中间浅：选“沿喉部圆弧径向插补”时刀尖随齿宽位置升降（公式见结果），选“固定深度”时只能开到两端槽底的高度。

螺杆转子：① 三螺杆泵按 Mimmi & Pennacchi 摆线型线由参数生成：主动螺杆齿根 r、齿顶 (1+k)r，齿面为外摆线；从动螺杆齿顶 r、齿根 (1−k)r，齿面为外次摆线，两者共轭（已仿真校核）。② 压缩机等转子：粘贴端面坐标或读取 DXF（直线、圆弧、多段线、样条），程序自动找出一个齿槽，转成轴向截面后再算刀具。三螺杆主动螺杆齿根是摆线尖点，刀具对应处也是尖点，实际制刀按图纸加圆角；从动螺杆齿槽在齿顶附近内收（燕尾），盘铣刀铣不到那一小块，程序会给出偏差。

螺旋面的成形铣刀：零件螺旋面 S(r, z, θ) = (−r sinθ, r cosθ, z + pθ)，p = 导程/2π。盘铣刀安装角默认取分度圆导程角，刀具中心距自动迭代使刀具外径等于给定值；指型铣刀刀轴沿径向。接触条件 (S − C)·(n × a) = 0，从槽底开始按 θ 连续跟踪接触点，避免跳到假解。算出刀具后做两项校核：反算偏差——用刀具包络回零件，与目标型线比较，查加工不到的地方；全局过切——把整把刀具沿螺旋运动换算到端面，看是否切进齿槽另一侧或相邻齿。两项都在 2 µm 以内才说明这把刀可用。

外螺纹（含骨钉）：按轴向截面牙型生成螺旋面，再用与蜗杆相同的方法算成形车刀刃口（也可选盘形铣刀、指型铣刀）。普通螺纹按 ISO 68-1 基本牙型，外螺纹牙底取整圆弧 R = 0.1443P（d3 = d − 1.2269P）；梯形螺纹按 GB/T 5796，h3 = 0.5P + ac，牙顶宽 0.366P，牙底圆角取 0.5ac；锯齿形按 GB/T 13576 / DIN 513，承载面 3°、另一面 30°，h3 = 0.86777P，牙顶宽 0.26384P，牙底整圆弧 R = 0.12427P；骨钉 HA 1.5～5（35° / 3°）、HB 4、6.5（25° / 5°）按 ISO 5835 / ASTM F543 的大径 d1、芯径 d5、螺距 P、前侧圆角 r4（35° 或 25° 面与牙底之间）、后侧圆角 r5（3° 或 5° 面与牙底之间）和牙顶宽 e；标准中 e、r4、r5、α、β 是近似值（≈），HA 1.5、HA 2 按近似值构造时圆角放不下，程序按比例缩小并提示。牙侧角都从垂直于轴线的径向线量起，图中右侧为螺纹尖端方向。骨钉直径小、导程角大（小径处常到 10°～16°），车刀背离进给一侧的侧后角往往不够，需要按导程角倾斜安装或选“法向”前刀面。标准牙型的数值以标准原文和图纸为准，不一致时选“自定义牙型”逐项填写（切换时会先填入上一个牙型的数值）。牙顶圆角大于 0 时按全牙型车刀计算，刀具覆盖一个螺距并车出牙顶。

蜗杆成形车刀：刃口 = 前刀面与螺旋面的交线。轴向安装（ZA 刃口为直线）、法向安装（ZN，前刀面在分度圆处的齿槽法平面内）、偏置安装（ZI，前刀面偏离轴线 rb，左右齿面各用一把车刀，刃口均为直线）。有前角时前刀面绕刃口方向转 γ；“后刀面法向截面”给出磨刀用的廓形（深度 × cos(α+γ)/cosγ）。侧后角：进给一侧要加上齿根导程角，另一侧要减去齿顶导程角。

齿条：齿条齿面是平面、齿根是直线。指型铣刀刀轴垂直于齿条顶面、盘形铣刀刀轴水平并垂直于齿向，沿齿向直线走刀时，刀具廓形都严格等于齿条法向截面的齿槽（基本齿条梯形 + 齿根圆角），直齿、斜齿相同，也与盘铣刀外径无关；斜齿条只是分度步距变成端面齿距 πmn/cosβ。指型铣刀端面是平的，正好铣出直线槽底，没有齿轮那种槽底多铣或残留。成形插刀只用于直齿条。量棒沿齿向放在齿槽里：量棒尺寸 M = H + dp/2·(1 + 1/sinαn) − en/(2tanαn)，H 为分度线到基准面高度，en 为分度线处法向槽宽；理想量棒 dp* = πmn/(2cosαn)。

链轮、摆线齿轮、三角花键、棘轮：都是直齿，沿轴向走刀，刀具廓形 = 端面齿槽形状（指型铣刀刀轴沿齿槽对称线，盘形铣刀刀轴沿切向，插刀截面即齿槽）。指型铣刀端面是平的：齿槽底是外齿齿根圆弧（两角比中心深）时，两角会留下很小的残留，程序会给出数值。
链轮按 GB/T 1243 / ISO 606：分度圆 d = p/sin(180°/z)，齿根圆 df = d − d1，齿顶圆 d + (1 − 1.6/z)p − d1 ～ d + 1.25p − d1；标准只规定最大、最小齿槽（齿沟圆弧 ri 圆心在滚子中心，齿侧圆弧 re 在齿沟角端点与之外切、齿侧外凸）；也可选美标 / 日标 ASME B29.1、JIS B 1801 的 S、U 齿形（椿本技术资料公式）。三圆弧一直线齿形按机械设计手册公式（r1 = 0.5025d1 + 0.05，α/2 = 55° − 60°/z，r2 = 1.3025d1 + 0.05，β = 18° − 56°/z，r3 = d1(1.3cos(γ/2) + 0.8cosβ − 1.3025) − 0.05，γ/2 = 17° − 64°/z，da = p(0.54 + cot180°/z)），程序会自检 r3 圆心是否落在两滚子中心连线上距滚子 1.3d1 处。量柱测量距 MR：偶数齿 d + d1，奇数齿 d·cos(90°/z) + d1。
摆线齿轮（钟表）：轮齿理论齿顶高由齿数比决定（摆线相交处），实用齿顶高取 0.95 倍，齿顶圆弧半径 1.4·fa·m，齿根高 πm/2；小齿轮齿厚 1.05m / 1.25m，齿根高 (轮齿实用齿顶系数 + 0.4)m，齿顶分圆头、中尖拱、高尖拱。公式按 BS 978-2 的数据（H. Sparks 推导）。
三角花键按 DIN 5481（60° 系列，直线齿侧）：外花键槽角 60°，内花键槽角 60° − 360°/z，名义齿厚 = 槽宽 = 分度圆上半个齿距（弧长）；14 个规格的分度圆、大小径、槽底圆角、实际齿厚 / 槽宽和量棒尺寸取自 DIN 5481 表（量棒按 2019 版）（外花键分精配、粗配），默认按公差中值，可选上下限，量棒尺寸与表中 MRe / MRi 一致。外花键也可选渐开线齿侧（m = D/z，α = 30° − 90°/z，槽底为齿根圆 + 圆角，圆角取不使渐开线起始点高于 DFe max 的最大值）。
棘轮按机械设计手册：da = mz，h = 0.75m，齿顶厚 a = m，齿槽夹角 θ = 60° 或 55°；作 ∠BEC = θ 的圆与齿根圆相交得工作面 CE。工作面后倾（齿倾角，一般 15°～20°），所以棘轮用单角铣刀铣：刀轴垂直于工作面，端面刃铣工作面，锥面刃铣齿背，刀尖圆弧 = 槽底圆角；也可用成形插刀。指型铣刀做不了不对称齿槽。

回转体成形车刀：输入零件轮廓（轴向位置 z，直径或半径），刀尖对准零件最小半径。C = √(r² − (r₁ sinγ)²) − r₁ cosγ 为前刀面内的廓形深度；棱体刀廓形深度 P = C·cos(α + γ)（垂直于后刀面量）；圆体刀各点半径 Rx = √(R0² + C² − 2R0·C·cos(α + γ))，刀具中心高于工件中心 R0·sinα。

DXF 文件：① 下载纯轮廓 DXF：文件里只有刀具轮廓一条线（等点距时为多段线，“圆弧 + 直线拟合”时为一条带圆弧的多段线），没有任何标注，直接导入数控磨床、线切割等设备。② 下载 DXF 文件：刀具轮廓仍单独放在 CUTTER（或 TOOL）层、只有一条线；其他内容都不与它相交、不共点：MARK 层在轮廓右侧外面标出齿根圆（刀尖 H = 0，并注明槽底多铣 / 残留量）、渐开线起始圆、分度圆、齿顶圆对应的高度和刀径；PART_REF 层画零件的齿顶圆、分度圆、基圆、渐开线起始圆、齿根圆（螺纹、蜗杆为大径、参考直径、小径）；零件齿槽整体移到刀具左侧（螺纹、蜗杆的轴向齿形移到右侧），避免与刀具重叠；CENTER 为刀具中心线；NOTES 为右侧说明栏（参数、结果、提示、图层说明）。格式为 DXF R12，单位 mm，中文按 AutoCAD 的 \U+ 编码写入，字体 gbenor.shx + gbcbig.shx，若显示问号请把文字样式 CN 改成任一中文字体。“复制 DXF 文本”复制的是同一文件的文字内容，一般用不到。

刀具坐标输出：① 等点距坐标点：沿廓形每隔“点距”取一点，相邻点连成直线。曲线段的误差很小，但廓形上的尖角（如齿面与倒角的交点）可能落在两点之间被削掉：倒角处（折角 30° 左右）最大约为点距的 1/10，折角越大削得越多。点距最小 0.02，这时倒角尖角仍可能差 2 µm 左右，所以要求 1 µm 以内时请用“圆弧 + 直线拟合”。② 圆弧 + 直线拟合：按“拟合误差”自动分段，用最少的圆弧和直线逼近程序算出的理论廓形；刀尖平底、倒角等直线段保持为直线，尖角和曲率突变点（直线接圆角、圆角接渐开线）作为段的端点保留。选“相切连续”时用双圆弧逐段拟合，每段终点的切向与廓形一致，连接处没有折角（廓形本身的尖角除外）；选“允许微小折角”时每段用过三点的圆弧，段数更少，连接处折角一般只有百分之几度。表中给出每段的起点、终点、圆心、半径和实测偏差，DXF 中为真正的 ARC / LINE 图元，可直接用于磨床或线切割编程。

直齿：刀轴沿齿槽对称线，刀具轴向廓形 = 端面齿槽廓形。斜齿：刀轴垂直并相交于齿轮轴线，沿螺旋线进给；对每个齿面点求“齿面法线与刀轴相交”的接触点，得到精确的刀具回转廓形。图中虚线为分度圆处的法向截面，供对比。

齿形修正：修缘量从修缘高度起点按直线或抛物线增加，到齿顶达到 Ca；倒角按“高度 × 宽度”给出：高度从齿顶圆沿径向往下量，宽度沿齿顶圆从原齿顶角往齿中间量，两腿相等即 C 型倒角；倒圆为与齿面、齿顶圆同时相切的圆弧。留磨量沿齿面法向把刀具每侧收窄 q，只影响刀具，图中黑线仍是成品齿形；挖根量让刀具在齿根过渡区比成品多铣 pr，磨齿时砂轮不碰齿根、不留台阶，过渡区内两者平滑衔接。斜齿时以上修正都按端面截面计算。

图纸核对：程序把图纸上的齿顶圆、齿根圆和按标准公式（齿轮 ha*、c*、变位；花键按 GB/T 3478.1 或 DIN 5480 齿形）算出的值对比，在结果里列出差值。外齿齿顶圆偏大、齿根偏浅（内齿反过来）这类有干涉风险的偏差会提示向客户确认；齿根更深、齿顶缩短这类常见设计只列出不报警。程序计算一律以图纸数据为准，核对结果只作提醒。

花键没有检测数据时：在“精度等级换算”里填公差等级（如 6），程序按 GB/T 3478.1 的实际齿厚（外花键 h）或实际齿槽宽（内花键 H）公差中值设计刀具，不再用理论齿厚。“取值位置”可改为下限或上限。

图纸检测数据：选择齿厚依据（跨棒距、公法线或直接给齿厚）并填写上下限后，程序反算实际齿厚，并自动代替“齿厚减薄”。斜齿奇数齿用量球测量时，跨棒距按常用近似公式计算。一般按公差中值设计新刀；刀具磨损后槽变窄（外齿跨棒距变大、内齿棒间距变小），所以也可以按槽最宽设计，给磨损留出空间：外齿取下限，内齿取上限。填了渐开线起始圆后，程序会检查渐开线是否从这个圆（外齿）以下开始，齿根圆角越大起始圆越高。齿顶圆、齿根圆可直接按图纸填写，用来代替系数。

指型铣刀轴向进给，刀尖端面是平的（即使磨成内凹，转起来最低的也是外缘一圈），直齿的槽底只能铣成直线；斜齿时工件边进给边转动，槽底中间一段接近圆弧。3D 图中的齿槽按刀具实际扫出的形状显示。外齿：选“角部到位”时槽底中心比根圆略深（见“槽底中心多铣”），选“中心到根圆”时圆角处会留下少量残留。内齿的槽底根圆弧向刀尖凸出：默认“中心到根圆”，直线过槽底中心、圆角重新相切，两角比根圆略深（见“两角多铣”）；选“两角到位”时圆角不变、槽底中心略浅。DXF 可粘贴到文本文件另存为 .dxf，图层 CUTTER 为刀具廓形。
