每个公式从哪来、怎么一步步算出来。图中齿形和例题数字都按公式实时计算。

00符号和例题

全文用同一组例题，方便对照
符号含义符号含义
m模数z齿数
α压力角（分度圆）x变位系数
ha*齿顶高系数（一般 1）c*顶隙系数（一般 0.25）

例题齿轮：m = 3，z = 24，α = 20°，x = +0.2，ha* = 1，c* = 0.25；配对齿轮 z2 = 40，x2 = 0；量棒 dp = 5。
例题花键：m = 2，z = 24，αD = 30°，平齿根。
齿轮和花键的公式看着多，其实都是从几个基本关系推出来的。我们一个一个拆开算。

01分度圆 d = m z

一圈的周长 = 齿数 × 齿距
  1. 分度圆周长上排着 z 个齿距：π d = z p
  2. 所以 d = z p / π。p 里总带着 π，不好用
  3. 规定 m = p / π，叫模数，按标准系列取整数或简单小数
  4. 代回去：d = m z，p = π m
例题：
分度圆一圈排满 z 个齿距。把齿距除以 π 定义成模数，分度圆直径就是模数乘齿数。

02齿顶圆、齿根圆

从分度圆往外加齿顶高，往里减齿根高
  1. 标准齿条：齿顶高 ha* m，齿根高 (ha* + c*) m，多出来的 c* m 是顶隙
  2. 变位 x：刀具往外退 x m，齿顶高、齿根高一起变：ha = (ha* + x) m，hf = (ha* + c* − x) m
  3. 外齿轮：da = d + 2ha，df = d − 2hf
  4. 内齿轮方向相反：da = d − 2ha，df = d + 2hf。内齿轮变位按 DIN 3960 的符号（正变位 = 齿廓离开轴线、齿槽变宽）：ha = (ha* − x) m，hf = (ha* + c* + x) m；国内有的图纸符号相反，计算前要先确认
  5. 全齿高 h = ha + hf = (2ha* + c*) m，和变位无关
例题：
变位传动的中心距如果不等于标准中心距，齿顶圆还要再减一个“齿顶高变动量”，见第 08 节。
齿顶圆是分度圆加两个齿顶高，齿根圆是减两个齿根高。变位以后，齿顶高和齿根高此消彼长，全齿高不变。

03基圆 db = d cos α

啮合线和基圆相切，和分度圆的交点是节点
  1. 渐开线齿轮的受力方向（啮合线）始终和基圆相切，切点 N
  2. 啮合线穿过分度圆上的节点 P，和 P 点切线的夹角就是压力角 α
  3. 直角三角形 O–N–P：斜边 OP = r，直角边 ON = rb，夹角 ∠NOP = α
  4. 所以 rb = r cos α，db = d cos α
  5. 基圆上的齿距叫基节：pb = p cos α = π m cos α
例题：
啮合线和基圆相切，又穿过节点。连上圆心就是一个直角三角形，基圆半径等于分度圆半径乘以压力角的余弦。

04渐开线函数 inv α = tan α − α

绳子从基圆上展开，绳头走出的轨迹就是渐开线
  1. 绳子绕在基圆上，从 B 点开始拉直展开，绳头 K 画出渐开线
  2. 拉直的绳长 NK = 展开的弧长 BN：NK = rb (θ + αK)
  3. 三角形 O–N–K 是直角三角形：NK = rb tan αK
  4. 两式相等：θ = tan αK − αK，记作 inv αK（α 用弧度）
  5. K 点所在圆的半径：rK = rb / cos αK，也就是 cos αK = rb / rK
例题：
绳长等于弧长，绳长又等于基圆半径乘正切。两边一减，就得到渐开线函数：正切减角度。

05变位后的齿厚 s = m(π/2 + 2x tan α)

刀具往外退 x m，齿轮分度圆上的齿就变胖
  1. 标准安装时，齿条中线和齿轮分度圆相切，齿厚 = 齿槽宽 = π m / 2
  2. 刀具往外退 x m，和分度圆相切的变成了刀具上一条更靠齿顶的线
  3. 刀齿在这条线上变窄，两侧各窄 x m tan α（齿面斜度 α）
  4. 刀齿窄多少，切出来的齿就胖多少：s = π m / 2 + 2 x m tan α
例题：
刀具每往外退一点，在分度圆上的刀齿就窄一点，两边各窄 x m 乘以正切阿尔法，齿就胖了两倍这么多。

06任意圆上的齿厚

已知分度圆齿厚，求任意直径 dy 上的齿厚
  1. 分度圆上半个齿厚对应的圆心角：ψ = s / d
  2. 齿面是渐开线，从分度圆到 dy，齿面的极角变化 inv αy − inv α
  3. dy 上半齿厚角：ψy = s/d + inv α − inv αy，其中 cos αy = db / dy
  4. 齿厚（弧长）：sy = dy (s/d + inv α − inv αy)
  5. 齿顶圆上 sa 算出来 ≤ 0，就说明齿顶变尖了；一般要求 sa ≥ 0.25 m（硬齿面取 0.4 m）
例题：
齿越往外越窄。用渐开线函数修正一下角度，就能算出任意圆上的齿厚，齿顶会不会变尖也是这样算的。

07斜齿轮：法面和端面

刀具按法面参数做，齿轮尺寸按端面算
  1. 把分度圆柱展开成平面，齿线是倾斜 β 的直线
  2. 垂直于齿线量是法面齿距 pn，沿圆周量是端面齿距 pt：pn = pt cos β
  3. 除以 π：mt = mn / cos β，分度圆 d = mt z = mn z / cos β
  4. 齿高在两个面里一样，斜度被拉宽：tan αt = tan αn / cos β
  5. 基圆 db = d cos αt；基圆螺旋角 tan βb = tan β cos αt；当量齿数近似 zv ≈ z / cos³β
例题（mn = 3，z = 24，αn = 20°，β = 15°）：
斜齿轮有两套参数：法面的和刀具一样，端面的用来算尺寸。两者之间只差一个螺旋角的余弦。

08中心距和啮合角（变位传动）

两个齿轮都变胖了，就只能往外挪
  1. 标准中心距：a = m (z1 + z2) / 2
  2. 无侧隙啮合：一个齿轮的齿厚 = 另一个的齿槽宽，在新的节圆上成立
  3. 把这个条件用第 06 节的公式写出来、整理，得到：inv α′ = inv α + 2 (x1 + x2) tan α / (z1 + z2)
  4. 基圆不变：a cos α = a′ cos α′，所以 a′ = a cos α / cos α′
  5. 中心距变动系数 y = (a′ − a)/m；齿顶高变动系数 Δy = (x1 + x2) − y，齿顶圆各减 2Δy m，保证顶隙
例题（z1 = 24、x1 = 0.2，z2 = 40、x2 = 0）：
变位让齿变胖，两个齿轮只能往外挪。挪多少由啮合角决定，而啮合角又可以用渐开线函数直接算出来。

09重合度 εα

实际啮合线长度 ÷ 基节 = 平均同时啮合的齿对数
  1. 接触点只在啮合线上走：从 A（从动轮齿顶进入）到 E（主动轮齿顶离开）
  2. 从切点 N1 量到 E：√(ra1² − rb1²)；从 N2 量到 A：√(ra2² − rb2²)
  3. N1N2 = a′ sin α′，所以实际啮合线 gα = √(ra1² − rb1²) + √(ra2² − rb2²) − a′ sin α′
  4. 相邻两对齿在啮合线上相隔一个基节 pb：εα = gα / pb
  5. εα = 1.4 表示：40% 的时间两对齿啮合，60% 的时间一对齿啮合；一般要求 εα ≥ 1.2
例题：
接触点在啮合线上从 A 走到 E。这段长度除以基节，就是平均有几对齿同时在啮合。

10公法线长度 Wk

两个平行量爪跨 k 个齿，量爪之间的连线和基圆相切
  1. 两个量爪都垂直于同一条基圆切线，接触点都在这条切线上（渐开线的法线都和基圆相切）
  2. 沿切线量：中间跨了 k − 1 个基节，再加一个基圆齿厚：Wk = (k − 1) pb + sb
  3. 基圆齿厚由第 06 节公式（dy = db，αy = 0）：sb = db(s/d + inv α)
  4. 代入整理：Wk = m cos α [π (k − 0.5) + z inv α] + 2 x m sin α
  5. 跨齿数让接触点落在齿高中部：k = z α/180° + 0.5（x = 0 时），取整
例题：
量爪之间的连线正好和基圆相切，所以公法线长度就是几个基节，加一个基圆齿厚。

11量棒距 M

先求量棒中心在哪个圆上，再加减一个量棒直径
  1. 量棒同时碰到齿槽两侧齿面，碰点处的法线都过量棒中心，并且和基圆相切
  2. 沿这条法线，量棒中心到齿面的距离 = dp/2，换成基圆上的角度：dp / db
  3. 外齿：inv αM = inv α + s/d + dp/db − π/z（s 为分度圆齿厚）
  4. 量棒中心圆：dM = db / cos αM
  5. 偶数齿 M = dM + dp；奇数齿 M = dM cos(90°/z) + dp
  6. 内齿：inv αM = inv α + e/d − dp/db（e 为分度圆齿槽宽），棒间距 M = dM − dp（奇数齿乘 cos(90°/z) 再减）
  7. αM 要从 inv αM 反求，用迭代（计算器里自动算）
例题：
量棒两边碰到齿面的法线都和基圆相切。先用渐开线函数求出量棒中心所在的圆，再加上一个量棒直径，就是量棒距。

12渐开线花键基本尺寸（GB/T 3478.1 / ISO 4156）

花键是“短齿”的渐开线齿轮，压力角 30°、37.5° 或 45°
  1. 分度圆 D = m z，基圆 Db = m z cos αD，齿距 p = π m
  2. 基本齿槽宽 = 基本齿厚：E = S = π m / 2（花键不变位）
  3. 30° 平齿根：外花键大径 Dee = m(z + 1)，小径 Die = m(z − 1.5)
  4. 30° 平齿根：内花键大径 Dei = m(z + 1.5)，小径 Dii = m(z − 1)
  5. 圆齿根时外花键小径、内花键大径分别取 m(z − 1.8)、m(z + 1.8)；37.5°、45° 的系数不同，按标准表取
例题：
和齿轮相比，花键的齿顶高只有 0.5 m，齿短而粗，所以压力角要取大一些，强度高、承载均匀。
渐开线花键可以看成短齿的渐开线齿轮。分度圆、基圆、齿距的算法和齿轮完全一样，只是齿顶高只有半个模数。

13作用齿槽宽和实际齿槽宽

花键的公差为什么分“作用”和“实际”
  1. 实际齿槽宽 E：单个齿槽量出来的宽度（用量棒测）
  2. 作用齿槽宽 Ev：把所有齿槽的齿距误差、齿形误差、齿向误差都算进去以后，“能装进去的那根理想外花键”的齿厚。误差让孔“变紧”，所以 Ev ≤ E
  3. 内花键：Ev min = π m / 2（H 基本偏差为 0）；Emin = Ev min + λ；Emax = Ev min + (T + λ)
  4. 外花键：Sv max = Ev min + esv（h 为 0，f、e、d 为负）；Smax = Sv max − λ；Smin = Sv max − (T + λ)
  5. T 是加工公差，λ 是综合误差（齿距、齿形、齿向）的影响量，数值按公差等级查表
验收时：作用尺寸用综合量规（通规），实际尺寸用量棒或止规。两个都合格，花键才合格。
花键要同时管两件事：单个齿槽量出来是多少，和所有误差叠加后还能不能装进去。前者叫实际齿槽宽，后者叫作用齿槽宽。

14矩形花键（GB/T 1144）

规格写成 N × d × D × B，小径定心
  1. N 键数，d 小径，D 大径，B 键宽（槽宽）
  2. 国标采用小径定心：小径精度最高，可以磨削；大径、键宽主要保证不干涉和传扭
  3. 键高 (D − d) / 2；分轻系列、中系列，尺寸按标准表选，没有复杂的公式
  4. 标记例：内花键 6×23H7×26H10×6H11，外花键 6×23f7×26a11×6d10
矩形花键简单得多，四个数：键数、小径、大径、键宽。国标用小径定心，所以小径的精度要求最高。

15动手算一算

改参数，每一步结果实时更新
计算器只算基本尺寸（不含公差）。内齿轮的变位系数按“正变位 = 齿槽变宽、齿变薄”处理，图纸用的符号规定不同时要换号。斜齿轮量棒距用端面公式（量棒直径按法面），偶数齿是精确值，奇数齿是近似值。
